# RAG Specialist Context — Current Stage

## Objective
Maintain a production-oriented, low-cost document ingestion and retrieval component.

## Owns
- `rag/rag_pipeline.py`
- `contracts/rag_contract.json`
- retrieval/indexing tests

## Current architecture
`document -> PDF/text extraction -> deterministic chunking -> replaceable embedding provider -> local persistent Qdrant -> score-filtered retrieval`

## Current provider
The default provider is `LocalFastEmbedProvider` using:
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
at 384 dimensions.

Gemini Embedding 2 remains an optional provider. It must not be required for normal low-cost development.

## Contract
`retrieve(query, top_k) -> [{id, text, source, page, score}]`

`index_documents() -> {indexed, unchanged, failed, chunks}`

## Important guarantees
- Empty queries return [].
- Provider returns exactly one vector per input.
- Qdrant dimension must match the active provider.
- Retrieval filters scores below `RAG_MIN_RETRIEVAL_SCORE`.
- Incremental indexing uses a manifest.
- New vectors are written before stale vectors are removed.
- Runtime vector/database state is not committed to Git.

## Do not
- implement agent logic
- implement FastAPI routes
- execute paid API calls by default
- silently rebuild or delete a vector collection on dimension mismatch

## Tests
Use the deterministic embedding provider for offline tests. Do not require a network model download in CI tests.

# Backend / Database Specialist Context — Current Stage

## Objective
Expose a stable versioned API and persist chat records with minimal infrastructure.

## Current stack
- FastAPI
- Pydantic v2
- SQLAlchemy 2
- SQLite by default

## API
Base path: `/api/v1`

- GET `/documents`
- POST `/documents/upload`
- POST `/documents/index`
- POST `/chat`
- GET `/health`

Contract: `contracts/backend_api_contract.json`

## Upload guarantees
- filename normalized with `Path.name`
- only .pdf/.md/.txt accepted
- size checked while streaming
- upload first goes to a temporary file
- final replacement is atomic

## Error handling
Clients receive safe generic 500 messages. Detailed failures are logged server-side.

## Persistence
SQLite is the default local database. Runtime DB files are ignored by Git.

## Do not
- move RAG implementation into API code
- put frontend business logic in FastAPI
- expose raw exception strings to clients

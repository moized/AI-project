# Frontend / Deployment Specialist Context — Current Stage

## Objective
Provide a thin UI and reproducible local deployment around the backend.

## Frontend
Streamlit communicates only with the versioned FastAPI API.

It must not write directly into RAG/Qdrant/database internals.

## Deployment
Docker Compose contains separate backend and frontend services.

Backend:
- port 8000
- persistent Qdrant volume
- persistent SQLite runtime volume
- persistent FastEmbed cache

Frontend:
- port 8501
- waits for backend health

## Runtime state
Do not commit:
- qdrant_storage/
- runtime/
- *.db
- model caches
- .env

## Testing
Keep UI thin. Backend API tests are the primary integration boundary.
